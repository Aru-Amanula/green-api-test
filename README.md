# Тестовое задание: Веб-интерфейс для GREEN-API

Простая веб-страница, реализованная в рамках тестового задания на позицию **Специалиста технической поддержки 2 линии**. Позволяет проверять базовые методы API сервиса GREEN-API без использования бэкенда[cite: 1].

---

## 🛠 Поддерживаемые методы

- **`getSettings`** — запрос текущих настроек инстанса[cite: 1].
- **`getStateInstance`** — проверка статуса авторизации (возвращает `authorized`, если QR-код отсканирован)[cite: 1].
- **`sendMessage`** — отправка текстового сообщения в WhatsApp[cite: 1].
- **`sendFileByUrl`** — отправка файла/картинки по прямой URL-ссылке[cite: 1].

---

## 🚀 Как быстро проверить

1. Зарегистрируйтесь на [green-api.com](https://green-api.com) и создайте бесплатный инстанс на тарифе **Developer**[cite: 1].
2. Свяжите ваш WhatsApp через QR-код (`WhatsApp` -> `Связанные устройства`)[cite: 1].
3. Скопируйте **idInstance** и **ApiTokenInstance** из личного кабинета[cite: 1].
4. Откройте [опубликованную страницу](https://aru-amanula.github.io/green-api-test/) [cite: 1].
5. Вставьте ключи в поля ввода и вызывайте методы[cite: 1]:
   - Номер телефона нужно вводить **без плюса**, начиная с кода страны (например: `77771234567`)[cite: 1, 2].
   - Для отправки файла вставьте прямую ссылку на изображение (`.png` / `.jpg`)[cite: 2].

---

## 💻 Технические особенности

- **Чистый стек:** Написано на Vanilla JS, HTML5 и CSS3 без сторонних библиотек и фреймворков.
- **Интерфейс:** Двухколоночная верстка на CSS Grid (адаптируется под мобильные экраны)[cite: 1, 2].
- **Безопасность:** Ключи доступа не зашиты в код и вводятся только пользователем в браузере.
- **Взаимодействие:** Все запросы отправляются через нативный `fetch` (`GET` для статуса/настроек, `POST` для сообщений и файлов), а ответы выводятся в правое поле в формате formatted JSON[cite: 1, 2].
